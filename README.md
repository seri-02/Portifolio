# Portfólio - Jonathas Seri

Este repositório contém o código-fonte do meu portfólio pessoal, criado para apresentar meus projetos, habilidades e um pouco da minha trajetória na área de desenvolvimento.

## Sobre

Sou estudante / estagiário na área de sistemas e utilizo este portfólio para reunir os principais projetos que venho construindo, incluindo trabalhos acadêmicos, sistemas com regras de negócio e aplicações feitas para praticar e evoluir tecnicamente.

A proposta deste portfólio é facilitar a visualização dos meus projetos de forma mais clara, organizada e acessível, especialmente para recrutadores.

## Objetivo do portfólio

Este portfólio foi desenvolvido para:

- apresentar meus principais projetos de forma visual e organizada
- destacar tecnologias com as quais já tive contato
- reunir links importantes, como GitHub e LinkedIn
- servir como vitrine profissional da minha evolução na programação

## Projetos em destaque

Alguns dos projetos apresentados no portfólio:

- **Sistema de gerenciamento**  
  Projeto mais completo, com foco em organização, controle e lógica de negócio aplicada a uma necessidade real.

- **Projeto acadêmico em C**  
  Trabalho desenvolvido em grupo durante a faculdade, com participação em etapas importantes da construção do sistema.

- **Projetos em Java**
